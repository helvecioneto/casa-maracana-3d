# Casa Maracana — 3D

Visualização 3D interativa da Casa Maracana (Santarém/PA), gerada pelo Casa3D.

**Abrir:** https://helvecioneto.github.io/casa-maracana-3d/

- Arraste para girar, roda do mouse para aproximar.
- **Caminhar (Tab):** anda pela casa em primeira pessoa (WASD + mouse).
- **Andares:** mostre o térreo ou o superior separadamente; "Ocultar forros e telhado" mostra por dentro.
- **Sol:** escolha a data e a hora para ver a iluminação real do local.
- **Foto HQ:** renderização fotorrealista (path tracing) da vista atual.

Página estática exportada com `npm run exportar -- casa-maracana --ocultar-endereco`.
Para atualizar, exporte de novo para esta pasta e faça commit/push.
